# Piercer Binary Offset, Endian & x64 Lab

Conversor Little/Big-Endian, cálculo RVA ↔ File Offset (RAW), aritmética Hex e mapa de registradores x86/x64

## Funcionalidades

- **Seções principais**: Conversor Endianness & Ponteiros, Calculadora RVA ↔ File Offset (Seção PE), Mapa de Registradores x86 / x64
- **Persistência automática**: salva alterações automaticamente no navegador (`localStorage`).
- **Multilíngue**: suporte integrado com botão de troca de idioma (`PT / EN / ES`).

## Como Executar

1. Execute `start.bat` para iniciar o servidor local na porta `8157`, ou abra `index.html` diretamente no navegador.
2. Acesse `http://localhost:8157`.
