# Piercer Binary Offset, Endian & x64 Lab

convert Little/Big-Endian, cálculo RVA ↔ File Offset (RAW), aritmética Hex and mapa of registradores x86/x64

## Features

- **Main Sections**: convert Endianness & Ponteiros, calculator RVA ↔ File Offset (Seção PE), Mapa of Registradores x86 / x64
- **Auto-Save**: automatically persists changes in the browser (`localStorage`).
- **Multi-Language**: built-in language switcher (`PT / EN / ES`).

## How to Run

1. Run `start.bat` to start the local server on port `8157`, or open `index.html` directly in your browser.
2. Open `http://localhost:8157`.
